# Hi, I'm Abdulmuhsen (AHAKuo)

I'm a writer who ended up making games. In high school I started building a fantasy universe called *Stories in Glass*, and eventually I realized the only way it would ever become the game I pictured was if I learned to make it myself. So I did.

I've been running [AHAKuo](https://ahakuo.com/), my one-person studio, since 2017. I write, code, draw, and do the audio, and I also voice act, mostly villains, demons, and the occasional whimsical fairy.

## Games

- **Neon Moon**: a metroidvania I'm making solo. The demo is out, and the full game is on its way.
- **SoUnd Is ToxIc**: a visual novel made in Ren'Py
- **Before Dark**: a mobile game
- **Lanes Shooter** and **Young Moon**: game jam entries

## Tools

Most of my tools exist because I got tired of doing something by hand in Unity. Once they worked well enough for me, I cleaned them up and released them.

- **Signalia Pro**: the big one. UI, pooling, events, save/load, and transitions in a single Unity toolkit.
- **Structura**: the utilities, extensions, and small helpers I end up reaching for in every project
- **Amazing UI Navigation**: makes menus behave properly with a D-pad or controller
- **2D Layer Organizer**: keeps sorting layers manageable in 2D projects

## Apps

- **Symphonia**: a fast, minimal, offline music player. I'd rather own my music than rent it, so I built something to play my local library without getting in the way.

## The long game

Everything I make is practice for *Stories in Glass*, a universe that connects every character I've written since high school into one big story. It's why I make games at all.
